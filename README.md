# Healthcare Gap Analysis in Egypt

## Project Overview
This project analyzes healthcare disparities across Egyptian governorates using Microsoft Excel and Power BI.

## Objectives
- Analyze healthcare indicators across governorates.
- Compare healthcare service availability.
- Identify healthcare gaps.
- Build an interactive dashboard for decision-making.

## Tools Used
- Microsoft Excel
- Power BI

## Project Files
- Excel datasets
- Power BI dashboard (.pbix)
- Project presentation (.pptx)


## Open the project

Download the repository and open the Power BI files with Microsoft Power BI Desktop:

- [Health Care Gap Dashboard Depi project.pbix](Health%20Care%20Gap%20Dashboard%20Depi%20project.pbix)
- [Charts(1).pbix](Charts%281%29.pbix)
- [KPI_layer.xlsx](KPI_layer.xlsx), included Excel workbook
- [depi presentation.pptx](depi%20presentation.pptx), project presentation

If a data refresh requests a file location, update the source paths in Power Query to your local copy of the workbook. The repository contains no hosted dashboard link. Refreshing the files on a fresh Windows installation has not been independently tested.
