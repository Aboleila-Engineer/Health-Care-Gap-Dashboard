# Healthcare Gap Analysis in Egypt

## Project Overview
This project analyzes healthcare disparities across Egyptian governorates using Microsoft Excel and Power BI.

## Objectives
- Analyze healthcare indicators across governorates.
- Compare healthcare service availability.
- Identify healthcare gaps.
- Build an interactive dashboard for decision-making.

## Tools Used
- Microsoft Excel
- Power BI

## Project Files
- Excel datasets
- Power BI dashboard (.pbix)
- Project presentation (.pdf)
